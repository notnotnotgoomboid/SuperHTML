# SuperHTML
A recreation of Superliminal in HTML.

Goals:
  - Create 3D movement with WASD and pointer controls.
  - Forced Perspective System
  - Non-Euclidean Gameplay

This is a project made for fun, and every piece of borrowed code will be credited. I do not intend to use any code that isn't already open-source.
If you don't want me to use your code PLEASE tell me I don't want to take something without permission.
